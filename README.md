# VEROXAI UNIVERSE — Immersive Edition

A multi-world React + Vite experience with React Three Fiber and Drei.

## Included in this upgrade
- Four distinct 3D environments connected in one scroll-controlled camera expedition.
- Interactive, glowing portal rings that navigate into their corresponding world pages.
- Shader-driven energy cores with animated vertex displacement, color blending and rim lighting.
- Transforming geometric artifacts with animated scale and rotation.
- Layered lighting, emissive materials, stars, sparkles and spatial environment rings.
- Mobile-responsive portal directory and touch-friendly scroll journey.
- Existing home experience, archive, navigation and world routes retained.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The 3D journey is embedded on the home page under the hero. Scroll inside the journey area to travel between environments, or tap/click a glowing portal or its matching portal label to open a world.
